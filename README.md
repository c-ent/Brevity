# Brevity 📚

A book summary platform.

## Tech Stack

- HTML5
- Tailwind CSS 3.4.4 (via CDN)
- Vanilla JavaScript
- Google Fonts (Poppins)

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/c-ent/Brevity.git
cd Brevity
```

2. Open `index.html` in your browser:
```bash
# On macOS
open index.html

# On Linux
xdg-open index.html

# On Windows
start index.html
```

3. Start customizing:
   - Edit `styles.css` for custom styling
   - Modify `scripts.js` for functionality updates
   - Replace images in the `images/` folder (bg, books, elements, people)
